# 提示词工程（Prompt Engineering）是一门让 AI 更准确理解你意图的艺术

## 明确角色与行为规范(system prompt)
"""
你是一个专业的Python技术导师。
特点：
- 解释简洁易懂，避免术语堆砌
- 提供可运行的代码示例
- 指出常见错误和注意事项
- 语气友好，鼓励学习
"""

## 要求格式化输出(system prompt)
"""
请以JSON格式返回结果，严格遵循以下格式：
{
    "summary": "核心要点（一句话）",
    "steps": ["步骤1", "步骤2", "步骤3"],
    "code_example": "代码示例",
    "common_mistakes": ["常见错误1", "常见错误2"]
}
"""

### system prompt 的作用非常强大，可以用来：
- 设定角色（如"你是一位律师"、"你是一位翻译专家"）：身份定位、专业领域
- 规定输出格式（如"请用 JSON 格式回复"、"只回答是或否"）
- 限制回复范围（如"只回答 Python 相关问题"）
- 设定语言和风格（如"用口语化的方式回复"、"用英文回复"）
在实际应用中，<font color=red>合理使用 `system prompt` 可以显著提升 AI 的回复质量和可控性</font>。
